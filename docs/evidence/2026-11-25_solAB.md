## VAE 32s 根因線索
日誌反复 `Failed to import MPS module: error=100000002` → **MPSGraph conv 導入失敗，conv 全部退回 matmul 分解**（profile `conv=0 linear=870`）——video VAE decode 32s 的主因候選。Metal 原生 conv kernel（MSL 或 im2col+matmul 優化）是後續提速重點，直接惠及所有成片（sol/exact 同受此 32s decode 拖尾）。

## 初步歸因（FACT/INFERENCE/UNKNOWN）
- FACT：sol 在 13-token-block 小尺寸（nqb≈9）下固定開銷遠大於节省，去噪 +10.4s，方向符合設計預期（sol 收益需 seqlen≥數萬 token 才成立）。
- FACT：sol 中間幀為純雜訊（vision 覆核）；exact 同 seed 同規格主體可辨 → 退化源於 sol 分支而非配方本身。
- FACT：degen 第一次跑在 DiT core load 38/50 處無聲中断（rc=1、無 jetsam/崩潰報告），重試後越過同一點——非確定性載入失敗。
- INFERENCE：雜訊來自塊選擇/補償數值路徑（scores 均值池化閾值過嚴 → 大量塊僅靠 pooled 補償），待 degen 結果二分確認。
- UNKNOWN：exact mid-frame 軀乾網格紋是否 int8 路徑固有效果（大尺寸 Golden 對比待測）。
