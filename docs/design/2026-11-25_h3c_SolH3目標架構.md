# h3.c 目標架構：對齊 Sol-H3-Spark（2026-11-25，v3）

依據：arXiv 2609.35110（Sol-H3 配方源文）、NVlabs/Sana `sol-engine` 分支 `models/minimax_h3/Sol-H3-Spark`（pinned 权重清單 checkpoints.json）、arXiv 2607.24027（Sol-Attn 算法）。

## 1. 兩段式跨解析度調度（官方語義，逐字對齊）
- Stage 1（內容與動作）：H3 draft DiT @ **672×384×124**，**4 步**（FastH3 VSA DataFree LoRA；Ref2VA 任務改用 transformer_ref + LightX2V Ref2VA-4step LoRA，預設 dense attention）。attention=VSA 90% video sparsity、64-token blocks。
- Latent handoff：learned H3 ×2 latent upscaler（LBH 3d-conv）→ **H3→LTX latent adapter**（Efficient-Large-Model 官方公開發布）。取代「VAE decode→re-encode」循環。
- Stage 2（細節精修）：**LTX-2.5-22b dev + distilled LoRA-450 @strength 0.8**，@1344×768，**3 步**，對乾淨凍結的 H3 audio context。語音/音軌由 Stage 1 原生音訊直通（官方即是如此輸出 stereo AAC）。
- Stage 2 conditioning：prompt-independent——離線用 canonical 精修 prompt（"4K, refined, high quality, cinematic detail, clean textures, natural motion"，經 INT8 Gemma+dev connector）算一次、快取 post-connector tensors；線上不載入 Stage-2 TE。
- Sol-Attn（僅 Stage 2 refiner）：每 Q-block 對 pooled-K block 分數 ŝ，選 S_i={j: ŝ_ij > μ_i + τ·σ_i}；**τ 逐步 1.0 / 1.25 / 1.5**（用戶基線 τ=1.3 為單步等效值）；**前 2 個 transformer 層恒 dense**（安全護欄）；prefix 行（text|cond-video|audio）與 target 行分路，prefix 走 exact KV sink。被跳過的 block 以 pooled 分數做 online-softmax 補償，非直接丟棄。
- 官方 DGX-Spark（GB10，119.68GiB 統一記憶體，與 M5 Max 128GB 同級）**全程 resident 56.2s 出片、零 offload**（FP8 DiT 23.4GiB + NVFP4 Qwen TE 14.6GiB 常駐）。

## 4. Milestone 重排（驗收=真出片+提速）
- M2（進行中）：Ref2VA + Pika-Flex-6step 折疊版 端到端小尺寸。
- M3：sol-attn Metal BlockSparse（pooled 64-block 選块 + online 補償 + 首 2 層 dense + τ 排程）——**無下載依賴，先開發**。
- M4：draft 全規格 672×384×124 4-step（FastH3 LoRA int8 resident，估 4×~8s=半分鐘內 draft）。
- M5：下載官方 upscaler/adapter/LTX-int8/NVFP4-TE → upscaler 原生移植 → 兩段式接通。
- M6：1344×768×124 端到端兩段式全速跑＋與 ComfyUI golden 畫質對比＋逐輪性能表。
- M7：ComfyX 直接調用 h3.c。

## 5. 與 O87 既有配方的差異記錄
O87 記錄之「sol_vae / Two-stage SelfLift 0.4→upscale / NVFP4 文字編碼 / sol-attn τ=1.3」即本配方族（Sol-Engine）之簡寫；設計以官方源文為準並保留 τ=1.3 為單步基線。Ref2VA 參考圖生影片於官方 = transformer_ref 分區 + Ref-KV cache（首步後跳過 ref query 列、K/V 常駐快取，轉 cross-attention）——h3.c 需照做以省 Ref2VA 成本。
