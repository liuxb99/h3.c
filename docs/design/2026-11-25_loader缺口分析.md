## 一、Comfy-Org 單檔格式事實（本地實測標頭）
- **DiT int8_convrot**（minimax_h3_ref2va_int8_convrot，1035 tensors／50 層）：保留原始 HF 命名；250 組三件套 `<stem>.weight`=I8[out,in] ＋ `<stem>.weight_scale`=F32[out,1]（逐輸出列）＋ `<stem>.comfy_quant`=U8[71|72]（UTF-8 JSON：`{"format":"int8_tensorwise","convrot":true,"convrot_groupsize":256}`；adaln 群 64）。量化範圍＝每層 qkv/out/fc1/fc2/adaln 五顆；norm/bias/embed/rope/time_embedder 維持 BF16/F32。`__metadata__.config` 內含完整超參（hidden 5376、50 層、56×128 heads、ffn 14336、text_dim 5120、adaln_out 96768、token_refiner 2 層）→ 可取代 config.json。無 adaln_t_table。
- **TE nvfp4_awq**（2054 tensors）：每層 7 顆線性 U8[out,in/2]（fp4 兩兩打包）＋ weight_scale=F8_E4M3[out,in/16] ＋ weight_scale_2=F32 純量 ＋ comfy_quant（`{"format":"nvfp4","full_precision_matrix_mult":true}` → 只需 dequant→BF16，不需 fp4 tensor core）；embed_tokens=I8＋F32 row scale；norm/bias/視覺塔 BF16。命名 `model.layers.N.*`、`visual.*`（engine 現用 `model.language_model.layers.N.*`、`model.visual.*` → 需名稱重寫對映）。
- **sol_vae int8**：另一架構命名 `decoder.blocks.*`（含 F16 scale1/scale2）；原始 video_vae 檔僅線性量化、conv 保留 F16。兩者 engine 皆無 loader。
- **LoRA int8_convrot**（blocks.46-49 三件套）：engine 全庫無 LoRA 碼 → 用 fused_flex_lora 融合檔繞開。

## 三、施工順序（loader→metal8）
1. ✅ safetensors：F8_E4M3 dtype、未知 dtype 跳過、`__metadata__` 捕獲（13:07 build clean；真實兩檔 header 全開：DiT 1035/TE 2054 tensors，meta 捕獲成功）
2. store→GPU 量化載入 API（✅ 一字节 I8/U8 直入）＋ h3.c 單檔模式：目錄僅一顆 .safetensors → 從 `__metadata__.config` 合成 config、跳過 index/FL2VA 檢查、TE 名稱對映自動啟用
3. DiT/TE/schedule：檔案 I8 直傳（含 adaln）、TE nvfp4→BF16 逐層窗口 dequant（GPU kernel）、embed I8→BF16
4. Metal：in-place FastHadamard（256/64 群）＋群 amax 量化 kernel；rotation＋group-quant 接入既有 a8w8 epilogue（檔案 row scale 取代 runtime amax）；逆旋折進 residual/rope/gate 融合點
5. 解除 int8×ssd_streaming 互斥：窗口載 I8（~0.7G/層）＋ MAP_RANDOM 雙緩衝預取，驗 24GiB 內跑 34G 檔
